# Security

This repository contains no credentials, no raw agent traces, and no private infrastructure details.

If you find a security issue:

- Do not open a public issue.
- Email the maintainers at the address on the GitHub organization profile, or use GitHub's private vulnerability reporting on this repository.
- Include the affected file, the risk, and a minimal reproduction.

The audit script rejects common key, token, private-IP, and home-path patterns, but it is a tripwire, not a guarantee. Redact before you commit.
